## Independent native tests

They exercise real public APIs: routing and migration account selection; values and opaque JSON validation; cached-prefix boundaries; streaming assembly and early connection cleanup; byte-level SSE parsing; typed errors; multi-threaded credential refresh and lock contention; atomic store updates; AWS STS signing/XML parsing; Azure identity cache invalidation; GCP ADC exchange; device-code polling; batch and media drivers; realtime turn boundaries; and loopback WebSocket masking, ping/pong, fragmentation, and invalid-frame rejection.

28 novel requests, generated by `tools/differential.py` without reading the corpus, match the Python reference: six distinct requests for each of four dialects and four migration requests. These cover Unicode, tool schemas, forced tool choice, structured output, tool history, sampling, and streaming requests.

## Reproduce

```sh
bundle install
bundle exec rake test
python tools/check_contract.py --contract /path/to/clean/pinned/lm15-contract --direction all
python tools/differential.py --python-repo /path/to/lm15-python
gem build lm15.gemspec
gem install --local ./lm15-0.1.0.gem
ruby -Ilib examples/offline.rb
```

The configured CI matrix is Ruby 3.2, 3.3, and 3.4; only 3.3.10 was executed in the authoring environment. The gem builds and installs independently of the contract checkout.

## Validation limits

The environment could not enforce the harness no-network namespace (`unshare -rn` unavailable); the harness reported `sandboxed: false`. Harness fixtures and injected transports were used, and native network tests connect only to loopback sockets. No provider key, paid API call, interactive OAuth login, cloud metadata service, or live provider WebSocket was used. Cloud source permutations beyond the native tests remain integration risks. Windows locking and other Ruby runtimes were not executed here.

See the README for deliberately stated API and transport differences. Passing the recorded corpus is evidence of compatibility with this pin, not a claim of live provider certification. Machine-readable totals are in `docs/validation.json`.
