## Independent native tests

65 Minitest tests, 533 assertions, zero failures/errors/skips. They exercise real public APIs: routing and migration account selection; values and opaque JSON validation; cached-prefix boundaries; streaming assembly and early connection cleanup; byte-level SSE parsing; typed errors; multi-threaded credential refresh and lock contention; atomic store updates; AWS STS signing/XML parsing; Azure identity cache invalidation; GCP ADC exchange; device-code polling; batch and media drivers; realtime turn boundaries; and loopback WebSocket masking, ping/pong, fragmentation, and invalid-frame rejection.

New regression tests additionally cover stream cleanup on provider/consumer
failure and interruption, secondary cleanup/warning failures, wrong-thread
close, all SSE line endings and byte split points, native assistant image/file
replay, citation replay, and refusal before credentials/transport. These tests
fail against the imported implementation. The history fixes deliberately
correct omissions shared with Python; their expected bytes come from the
contract rules and provider documentation, not Python's lost content. See
[history-content.md](docs/history-content.md).

28 novel requests, generated by `tools/differential.py` without reading the corpus, match the Python reference: six distinct requests for each of four dialects and four migration requests. These cover Unicode, tool schemas, forced tool choice, structured output, tool history, sampling, and streaming requests.

## Reproduce

```sh
bundle install
bundle exec rake test
python tools/check_contract.py --contract /path/to/clean/pinned/lm15-contract --direction all
python tools/differential.py --python-repo /path/to/lm15-python
gem build lm15.gemspec
gem install --local ./lm15-0.1.0.gem
ruby -Ilib examples/offline.rb
```

CI covers Ruby 3.2, 3.3 and 3.4 on Linux, plus Ruby 3.4 on macOS. It also
installs the built gem and runs its example and native tests outside the source
checkout, with dependencies installed from the gem specification. The local
installation check used fresh runtime dependencies, including OpenSSL 4.0.2 and
JSON 3.0.2. No reference or contract checkout is required by the installed gem.

The unchanged harness and independent comparison checks also run in CI.
Local reproduction commands above require a Python executable named `python`
and the matching Ruby interpreter on PATH.

## Validation limits

The fresh local harness run enforced `unshare -rn` and reports `sandboxed: true`;
independent comparison checks also ran with networking disabled. Native tests
ran with loopback access only and an empty temporary home. The original
2026-09-12 authoring run was unsandboxed; that is not the current validation
record.

No provider key, paid API call, interactive OAuth login, real cloud metadata
service, or live provider WebSocket was used. New assistant-media mappings have
documentation and offline byte-level tests, not live provider receipts. Cloud
source permutations beyond the native tests remain integration risks. Windows
locking and non-MRI Ruby runtimes were not executed here. Existing documented
provider limitations and the separate `.live` API remain unchanged.

See the README for deliberately stated API and transport differences. Passing the recorded corpus is evidence of compatibility with this pin, not a claim of live provider certification. Machine-readable totals are in `docs/validation.json`.
